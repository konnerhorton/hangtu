# Synthetic AGS4 test files

Made-up data for the M5 ingest tests (`docs/data/ingest.md` §11), the M6 QC tests (`docs/data/qc.md` §8) and the M7 dataset tests (`docs/data/datasets.md` §12). No company data (SPEC §12.3).
AGS files can't hold comments, so this page says what each one is for.

The files are written by `_make_files.py`. Change the data there and rerun it, rather than editing a file:

    uv run python tests/data/ags/_make_files.py

`tests/ags/test_files.py` fails if a committed file differs from what the script writes.

| File | Version | Purpose |
|---|---|---|
| `site_si.ags` | 4.2 | Three borings in SI, with `LOCA_DATM` `NAVD88` in every hole (the project's datum, `docs/work/vertical-datum.md`), with `GEOL_GEOL` codes (`FILL`, `ALV`, `TRC`) next to `GEOL_FORM`, and SPT increments on BH1 (a complete drive, and a refusal 125 mm into the test drive): PROJ, TRAN, UNIT, TYPE, ABBR, DICT (user-defined `XPPT`), LOCA, GEOL, SAMP, ISPT, LLPL, LNMC, GRAG, GRAT, PTST, CPTP, FGHG, FGHS, XPPT. It has `NP`, `Dry`, a refusal, `<1`, `>100`, `#2.65`, blanks, and `LLPL` and `LNMC` on the same specimen. BH3-B1 has a water content, NP limits and a grading, so it can be classified (`datasets.md` §6.6). |
| `site_us.ags` | 4.2 | The same data in US units (ft, in, psf, tsf, pcf for a density and for a unit weight, cm/s). Values are the SI values divided by exact factors, written to 10 significant figures (`10SF`, `9SCI`), so the twin-file test can use a 1e-9 tolerance. |
| `site_v404.ags` | 4.0.4 | The same borings, with `IPRG`/`IPRT` instead of `FGHG`/`FGHS`, `RUCS` with `RUCS_E` (removed in 4.2), the old unit spellings `degC` and `Bar`, and no headings added in 4.1 (`ISPT_N60`, `GRAG_PDEN`, `GRAG_SUFF`). |
| `defects.ags` | "4.9" | One case per ingest finding: an unknown version (`V000`), `Ft` (`U001`), `feet` (`U002`), a blank unit in `ISPT_CAS` (`U003`), `kPa` in `LOCA_NATE` (`U004`), `wet` in `LNMC_MC` (`T001`), an orphan `LLPL` specimen (`V10c`), and a user-defined group with no DICT entry (`V9`, `V18`). `M001` comes from `site_v404.ags`. |
| `qc_defects.ags` | 4.2 | One case per computed QC rule (`qc.md` §4.2–§4.10), on five holes in SI; it is clean for python-ags4 and ingest. BH1–BH4 are on a 50 m grid, BH5 has no coordinates, ground level, final depth or geology. Cases, by line: L001, L002, L003, G001 BH5 (58, ISPT 106); L004 HORN 64; L005 BH4 18.00 m (57); L006 (cascade of L007), L007 `LOCA_DATM` `NAVD88` in BH1–BH3 and `NGVD29` in BH4 (BH5 has no ground level, so its blank one doesn't count); G002 BH1 2.50–3.00 (70–71), BH2 log stops at 7.50 (73); G003 BH3 (75–76); D001 SAMP 85; D002 ISPT 96; D003 ISPT 103; D004 ISPT 98; D005 SAMP 89; D007 LLPL 122; D008 LLPL 121 (BH3-B1's `SPEC_DPTH` 0.05 m below its base); S001 97 ("hard"), 107 ("50/76 ft"); S002 99 (N 150), 108 (N 126, `41,81,57,75/113 N=126`, a complete test); accepted reports raising nothing 109–112 (`5,6,6 N=12`, `6,8/8,9,9,9 N=35`, and `50/3"` and `22-30-50/3in` with `ISPT_NVAL` blank); S003 BH4 (104–105); S004 100; S005 101; A001–A004 LLPL 118–121; P001 GRAT 143; P002 GRAT 137; P003 GRAG 130; P004 GRAT 145–147; K001 PTST 153, FGHG 159; C001 GEOL 77; C002 `LOCA_TYPE` absent. Cascades (a case that necessarily raises a second rule) are listed in `tests/qc/test_qc_acceptance.py`. |
| `joins.ags` | 4.2 | Edge cases for the depth and geology joins, in SI: an SPT mid-drive exactly on a layer boundary and at the base of the deepest layer, a refusal in the seating drive, nominal depths for 450, 100 and 200 mm and no `ISPT_NPEN`, a test in overlapping layers and one in a gap, a hole with no ground level and one with no geology, a code (`BED`) missing from `strata.csv`, an incomplete SPT (blank `ISPT_NVAL`), a refusal with `ISPT_NVAL` blank (`22-30-50/3"`, kept), lab specimens placed by specimen depth, sample midpoint and sample top, and samples whose tests `p.index_properties()` combines (`datasets.md` §13 #16): two Atterberg specimens at different distances from the water content's, two at the same distance, a sample with only a grading, and a specimen with both a water content and limits next to another at the same depth. The expected values are in `tests/datasets/`. |
